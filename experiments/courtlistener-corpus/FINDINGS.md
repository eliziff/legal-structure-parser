## Metadata required for usable links

Canonical URLs use the published cluster ID and slug. Preserve full cluster,
docket and court rows, not merely the fields needed by today's parser.
Cluster headmatter, summaries, syllabuses and related material can appear outside
an opinion's body. Whole-cluster opinion membership and order affect boundaries.

depend on whole-page membership and matching counts. An isolated source opinion
cannot establish those deployed anchors without the served page's evidence.

CAP reporter aliases use CAP's citation ordering, already implemented by the
consumer's `capPageCitations`: official, nominative, parallel, then vendor,
preserving order within each kind. The bulk citation CSV is not a substitute for
that ordering. Keep CAP JSON paths and source metadata; missing CAP JSON cannot
be represented as proof that parallel reporter pinpoints are absent.
